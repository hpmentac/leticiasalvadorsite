# Dra. Letícia Salvador — Site

Site institucional da Dra. Letícia Salvador — Odontologia, Botox, Preenchimento e Harmonização Orofacial.

Site estático (HTML, CSS e JavaScript), sem dependências e sem build.

## Estrutura
- `index.html` — página principal
- `styles.css` — estilos (paleta rosa + branco, fontes Palatino/Montserrat)
- `script.js` — interações (menu mobile, FAQ, scroll reveal)
- imagens (`.jpeg` / `.png`) e vídeo do atendimento (`.mp4`)

## Rodar localmente
Basta abrir o arquivo `index.html` no navegador.

## Publicação
Hospedado na Vercel (deploy automático a partir deste repositório no GitHub).
